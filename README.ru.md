# Free My TV — русская версия

Русский язык установлен по умолчанию для новых сборок. Сохранённый на телевизоре выбор языка имеет приоритет: переключите его в «Настройки главного экрана → Язык → Русский».

Время на главном экране, заставке, в прогнозе и во времени восхода/заката отображается в формате `00:00–23:59`.

В «Настройках главного экрана» отдельно включаются и выключаются погода, котировки, часы, дата и рекомендации TMDB. Валюты выбираются отдельно. Порядок и состав панели приложений изменяются в разделе «Панель приложений». Длинный список настроек прокручивается при перемещении стрелками пульта.

## Фотографии заставки

- **Android TV / Google TV:** «Настройки главного экрана → Фото для заставки → Выбрать фотографии». Выберите одну или несколько фотографий через системный файловый диалог, в том числе с USB-накопителя. На телевизоре должен быть установлен обработчик выбора документов. До 30 изображений сохраняются внутри приложения; после импорта накопитель можно отключить. Новый выбор заменяет предыдущий альбом. Пункт «Использовать рекомендации» возвращает стандартные фото TMDB.
- **LG / Samsung:** в том же разделе введите прямые HTTP/HTTPS-адреса изображений через пробел (до 30). Для них необходимо сетевое подключение. Пустая строка возвращает фото рекомендаций.

## Рекомендации TMDB

Включите «Рекомендации TMDB» и укажите собственный ключ API или Read Access Token в пункте «Ключ API TMDB». Ключ хранится на телевизоре. Пустое значение при сохранении удаляет введённый ключ. Можно также задать `tmdb_key` перед сборкой в `config.properties`.

Подборки показываются существующими карточками на вкладках «Обзор», «Фильмы» и «Сериалы». Источник учитывает поддерживаемые установленные стриминговые приложения и регион `tmdb_region` из `config.properties`. Без ключа, интернета или доступного в регионе контента подборки могут отсутствовать. Названия, жанры и описания запрашиваются на русском; наличие перевода зависит от TMDB.

## Сборка

Android: `./build.sh` (JDK 17+, Android SDK 34+, на Windows — WSL). LG: `python3 webos/build.py`. Samsung: `python3 tizen/build.py`. Подробности установки приведены в основном [README](README.md).

При обновлении уже установленного Android-приложения требуется прежний `freemytv.keystore`.
